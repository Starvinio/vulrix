# VULRIX

A tiny lisp-inspired rpn repl calculator.


## Goal

The goal of this project is to create a very straightforward, understandable parser.

That's why I am taking such inspiration from Lisp (it basically looks like an AST).


## Features
- [ ] Evaluate Expressions using basic arithmetic operators
  - [ ] (+ x y)
  - [ ] (- x y)
  - [ ] (* x y)
  - [ ] (/ x y)
- [ ] Evaluate Expressions in a nested way [e.g. (+ (* 2 3) 6)]
- [ ] Define Variables
- [ ] Define Functions
- [ ] Evaluate Files
